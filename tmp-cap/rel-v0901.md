## Blade2 0.9.0.1

0.9.0.0 的「发送键下面有一圈黑」没修对——那条暗弧不是焦点环，是 `AccentButtonStyle` 自带的一道 1 DIP 半透明黑描边。本次换样式栈外的修法，**只改 `MainWindow.xaml` 一个文件 + 版本号**，内核与其余 UI 不动。

### 真凶：描边，不是圆角也不是焦点

`AccentButtonStyle` 只 `BasedOn DefaultButtonStyle`，没重绑 `BorderBrush` / `BorderThickness`，于是继承 `ButtonBorderThemeThickness`(1 DIP) 和 `ButtonBorderBrush`（亮主题 = 半透明黑）。34×34 的强调粉圆上，底弧那道 1 DIP 描边被合成成 `#775F5F` —— 恰好是 40% 黑叠在强调粉 `#C69E9E` 上（0.6·(198,158,158) = (119,95,95)），所以在底下一圈看得见。

四周其实都有这道描边，但顶/左/右与亮色 compose 背景（`#E7E0E0`）抗锯齿混色，读起来只是浅色混合；只有底弧切线水平，整道描边落在整行像素上，才显出暗环。

### 排除法证据

- **不是圆角**：`CornerRadius` 24 超过 34 的一半，理论上自交。把半径改成 17 后做像素 diff，444/11211 个像素不同、最大差 18，纯抗锯齿噪声；暗弧在改前改后一模一样。
- **不是焦点环**：0.9.0.0 已加 `AllowFocusOnInteraction="False"`，暗弧照旧。
- **对照组**：同排 ＋ 钮 28×28、同样 `CornerPill`，但一直是 `BorderThickness="0"`，从来没有这道弧。给发送键设 `BorderThickness="0"` 后，暗弧区域暗像素数归零。

### 修法

发送键 `BorderThickness="0"`，与 ＋ 钮对齐；不再重绑任何色值（四态仍走系统强调色）。之前那版错误的圆角 token 和注释已全部回滚，`Theme/Tokens.xaml` 零改动。

### 验证

dev build 与装机 MSIX 0.9.0.1 两次截图，发送键区域暗像素均为 0，整颗是干净的强调粉圆。

### 安装

包是自签名的，**别的机器装之前先信任证书**，否则会报 `0x800B010A`：

```powershell
CertUtil -addstore TrustedPeople Blade2.cer
Add-AppxPackage Blade2_0.9.0.1_x64.msix
```

同版本号覆盖安装会被 `0x80073CFB` 挡，需先 `Remove-AppxPackage` 再 `Add-AppxPackage`。用户数据在包外，不受影响。
