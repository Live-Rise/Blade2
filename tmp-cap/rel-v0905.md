## Blade2 0.9.0.5

内核升到 `0.2.2-rc.1`（官方树零补丁），设置里新增**实验性功能页**（受管 bundle 选入）；壳侧重点修掉「点旧会话停在最早消息、贴底停在半空、滚动灰条」三个老毛病。

### 修：点旧会话不贴底（根因在内核报错格式）

内核 `0.2.2-rc.1` 起 `session/page` 的越界报错从 `…is past cursor <N>` 改成了 `session history cut <N> exceeds <游标>`。壳的游标探针按旧格式匹配永远不中，异常又被外层静默吞掉——分页历史整体失供，历史全靠跟随流快照逐条兜底渲染（绕过批记账），批尾贴底追逐因此不武装，列表停在顶部。

- 探针双格式兼容（`past cursor` / `history cut … exceeds` 都认，exceeds 后面即真实游标），对活内核实测 `page(游标)` 正常返回整段 journal
- 历史拉取失败不再静默：`%TEMP%\blade2-load.log` 留痕，下次再坏一眼可见
- 跟随流快照逐条渲染改为批记账：批内只渲染、批尾一次投影 + 一次追逐（这条兜底路径不再绕批，顺带消掉逐条全表投影的开销）

### 修：贴底追逐停在半空

旧追逐挂 `LayoutUpdated` 逐拍补发，两个失效点：拍何时来不受控（滚动偏移变化本身不脏布局）；「见底即收」之后异步图片解码、markdown 续建把内容再撑高就没人管——表现为随机停在半空。改为定时器驱动（64ms 一拍，拍拍必到），收敛判据换成「离底 ≤1px 且内容高度连续 3 拍静默」，预算 3s→8s；用户上翻、清屏、切会话立即收钩，绝不跟人抢滚动。

### 修：滚动灰条

快速滚动/大幅跳滚时整排灰色条形是 ListView 默认的滚动占位条。`ChatList` 关闭 `ShowsScrollingPlaceholders`，容器内容就绪才显示（代价是内容出现比占位晚半拍）。

### 实验性功能页

设置新增 experimental 分区：`OPTIONAL_BUNDLES` 迁 `dsh-official-bundles`（15 项受管 bundle），偏好落 LocalSettings（关了不回弹）；agent-team 启用即停 subagent；session-titles 默认开。

### 其它

- rust 侧修批：滚轮钩子取位（LL delta 在高字，低字读法是账本恒空的既有 bug）、钩子换气、估距追逐、dr4 wheel 步进
- i18n 28 语言随内核 0.2.2-rc.1 补齐

### 安装

包是自签名的，**别的机器装之前先信任证书**，否则会报 `0x800B010A`：

```powershell
CertUtil -addstore TrustedPeople Blade2.cer
Add-AppxPackage Blade2_0.9.0.5_x64.msix
```

从 0.9.0.4 及更早版本升上来直接装即可。**同版本号覆盖安装会被 `0x80073CFB` 挡**（包标识相同而内容不同，系统防篡改），需要先卸再装：

```powershell
Remove-AppxPackage (Get-AppxPackage Blade2).PackageFullName
Add-AppxPackage Blade2_0.9.0.5_x64.msix
```

用户数据在包外（`%LOCALAPPDATA%\Blade2`），卸载重装不受影响。
